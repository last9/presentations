What everyone tries first

"We'll just add guardrails to the prompt."

A prompt is an instruction — it runs before the model misbehaves. A tool call is a syscall — once code runs, your prompt is a suggestion.

Chipotle's support bot was jailbroken into writing code. The analyst takeaway: "enforce scope at the product level, not just in the prompt."

you can't contain a running process with English.

Defense, not hope · 1 of 3

"I'll read secrets that aren't mine."

Credentials sit in env vars, files, process memory — even old snapshots.

Encrypted to one identity

Per-credential Argon2id → AES-256-GCM, bound to (workspace, agent) at construction. Reach the store all you want — it's ciphertext you can't even name.

✓ a secret it wasn't given is ciphertext it can't read

"I'll run my own program."

It can write to its own dir — so it drops a binary and execs arbitrary native code.

Writable, but not executable

Landlock (kernel LSM) makes the agent's dir writable but withholds the exec bit. The kernel refuses the exec no matter how clever the code is.

✓ contained — the LSM doesn't care how clever the code is

Defense, not hope · 2 of 3

"I'll take the whole box down."

A hostile loop forks without end — on shared hardware, that starves every other tenant.

One process group per agent

Each agent is its own OS process group (Setpgid). Stop is a tree-wide SIGTERM → SIGKILL — the runaway and every child die together.

✓ the noisy neighbor dies inside one agent

"I'll burn $50k in a retry loop."

An agent stuck in a tool-error loop can outspend your team's monthly bill in an hour.

Check the budget before the call

Hard cap blocks; soft cap downgrades Opus → Haiku. Atomic per-(workspace, agent, model) counters in micro-USD integers — no float drift.

⛔ blocked before a single token is spent

Defense, not hope · 3 of 3

"I'll slip bad code in through your deploy."

Skills ship via a git webhook — poison the pipeline before the agent ever runs.

Every push is treated as hostile

HMAC-SHA256 verify · reject ../ & symlinks · strip setuid (mode & 0755). Deploy flips a symlink — it fully lands or nothing changes.

✓ verified, sandboxed, reversible

"A webhook told me to. So I did."

The confused deputy: not hacked, convinced. It acts with its own authority. (This was the Meta bot.)

It can only do what it was granted

Every skill declares its tools up front. Sensitive actions are deny-by-default — they need explicit approval, never the agent's own judgment.

✓ injection changes what it wants, not what it can do

"Why not just a container?"

A container shares the host kernel.

Namespaces change what a process sees. They don't change what the kernel does.

457 syscalls reachable
from a container → ~5 emulated devices in a
separate-kernel micro-VM
process→ container→ LSM→ micro-VM→ confidential VM

The boundary that holds doesn't share a kernel. Firecracker: ~125ms boot, no confirmed guest→host escape in production.

Anthropic runs Claude Code itself on Firecracker — and you can buy the same thing.

runc escapes land yearly. AWS: "does not consider a container … a security boundary."
