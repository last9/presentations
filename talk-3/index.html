Required baseline

What is an agent?

An LLM in a loop that takes actions, keeps state, and acts in the world, not a chatbot, not RPA.

it spends money Every turn of that loop is a metered LLM call. Token spend is the new blast radius.
THE ONE IDEA

Gate spend before the call, not on the invoice.

A budget you discover at month-end is an autopsy. A budget checked before the call is a control.

a hard cap removes the ability to overspend. a rate limit only throttles it.

The zero-trust design test applies to cost too: impossible beats tedious. A rate limit makes a runaway agent slower; a pre-call hard cap makes overspend past the limit impossible. Anthropic's framework names this threat directly: resource exhaustion, or loop amplification. Transition: here's what that runaway actually looks like.
The runaway · resource exhaustion

"I'll retry until it works."

A tool-error loop, a recursive plan, a cron that never settles. Loop amplification: an agent can spend more in an hour than your team spends in a month.

And it does it silently, one reasonable-looking call at a time.

Name it the way the framework does: resource exhaustion via loop amplification. The danger isn't one expensive call, it's ten thousand cheap-looking ones. Make it visceral, a retry loop overnight, a recursive plan that forks. Transition: and your billing dashboard won't catch it in time.
Why dashboards don't save you

Billing alerts fire after the money's gone.

Provider usage lags minutes to hours. By the time the alert pages you, the loop has run ten thousand times.

you can't alert your way out of a tight loop.

Pre-empt the obvious objection, "we have billing alerts." Alerts are detection, and detection lags minutes to hours; the loop runs thousands of times in that window. Detection is throttling, not removing. Transition: so move the check before the call.
Structural control · pre-call budget gate

Check the budget before the call.


func BudgetCheck(ctx, pool, workspaceID) (*Budget, error) {
    // SUM(cost_usd) for this month, in micro-USD integers
    if hardCap != nil && totalCost >= *hardCap {
        return &budget, ErrHardCapExceeded   // block the call
    }
    if softCap != nil && totalCost >= *softCap {
        return &budget, ErrSoftCapExceeded   // downgrade Opus → Haiku
    }
}
