Required baseline

What is an agent?

An LLM in a loop that takes actions, keeps state, and acts in the world, not a chatbot, not RPA.

the platform's job Run hundreds of these for different tenants on one binary, with no leaks between them.
THE ONE IDEA

Isolation is a codebase property, not a runtime hope.

A handful of boring Go rules make cross-tenant access something you can't express, not something you remember to prevent.

Act 1 · the Python original

A skill was just a module we imported.


def handle(name, input, ctx):
    # in-process: full filesystem, env, network, shared memory.
    # great for one trusted team. fatal for many tenants.

Shared process, shared globals, shared blast radius. Going multi-tenant broke every assumption, and forced the Go rewrite.

The rules that made isolation tractable

Four boring rules.

① Interfaces first, constructor injection

② No global state (only sentinel errors, metric descriptors)

③ One concept per package

④ Process-spawn model, each agent its own OS process

No global state is a security property: there's no shared singleton for one tenant's data to leak through.

The pattern, made concrete

Bind the tenant at construction.


// the store is the canonical example: workspace + agent baked in,
// so no method can reach another tenant's data.
func NewPGStore(pool, masterKey, workspaceID, agentID string) (Store, error)

// engine pool: per-(workspace, agent) instance, evicted when idle
pool sync.Map   // 30m TTL, 5m reaper

Concurrency without frameworks: x/sync/semaphore + plain goroutines, a per-channel mutex for ordering. No pool libraries.

How we trust it

Real implementations, not mocks.

Table-driven + testcontainers

Tests run against a real Postgres in a container. No mocks where a real implementation works, so the isolation we test is the isolation we ship.

Sentinel errors per package

Wrap with fmt.Errorf("...: %w", err); one concept owns its errors. Failures are legible, not stringly-typed.

Architecture as security.

The rules look like style. They're load-bearing: they make a whole class of cross-tenant bug unwriteable.
