Required baseline

What is an agent?

An LLM in a loop that takes actions, keeps state, and acts in the world, not a chatbot, not RPA.

it holds the keys That loop holds real credentials: AWS keys, Slack & Linear tokens.
THE ONE IDEA

Isolation must be structural, not conventional.

For secrets: bind access in the key and the constructor, not in a query you have to remember to write.

The nightmare

Agent A reads Agent B's API key.

engineer9 for Acme and the instance for Globex share a process pool and one Postgres.

If reading a neighbor's secret is one forgotten WHERE clause away, it will happen.

The usual answer

"Just scope every query."


SELECT value FROM secrets WHERE tenant_id = $1   -- hope nobody forgets this

That's convention: correctness rides on every developer, every query, forever. One missing predicate and the wall is gone.

a rule you must remember is a rule you will eventually forget.

Structural control · bound at construction

You can't name another agent's secret.


// Cross-agent access is structurally impossible: workspace_id and
// agent_id are bound at construction; the key is derived from them.
func NewPGStore(pool, masterKey, workspaceID, agentID) (Store, error)

type Store interface {        // no method takes another agent's id
    Get(ctx, name) (string, error)
    GetMasked(ctx, name) (string, error)
}
✓ contained, by the constructor, not by discipline
Defense in depth · encrypted at rest

A unique key per credential, derived, never stored.


// Argon2id: time=1, memory=64MB, threads=4, keyLen=32 (AES-256)
key := argon2.IDKey([]byte(masterKey), salt, 1, 64*1024, 4, 32)

// stored blob:  salt(32) || nonce(12) || AES-256-GCM(ciphertext)
random salt / credential random nonce / write master key never logged
The ergonomics that keep it safe

Make the safe path the easy path.

Masked reads

GetMasked returns AKIAIOSF...MPLE (first 8 + last 4). UIs never touch plaintext; values ≤ 12 chars become ****.

Return-secret-once

Webhook secrets come back only on creation. Later reads return empty: lose it, rotate it. No "GET my secret" endpoint to leak.

The newer exposure · credentials in the snapshot

Fast restore writes your token to disk.

One token, 65 plaintext copies in a 256MB memfile. SEV-SNP hides RAM from the host, but not from the agent's own code.

DEMO

Two agents. One tries to steal.

From Acme's store, reach for Globex's token. There's no API for it, and the bytes on disk are gibberish without Globex's derived key.

Honest limits

What this does not solve

master-key compromise

One master key derives every per-credential key. Guard it like crown jewels (KMS / Vault).

no rotation yet

No mechanism to re-encrypt all credentials under a new master key. On the roadmap.

The zero-trust maturity path: short-lived tokens, hardware-bound, reference-not-value. Anthropic's line: "rotating a credential you can grep out of a lockfile doesn't raise the cost."

Still, the headline holds: leaking a neighbor's secret isn't a bug to avoid. It's an operation that doesn't exist.
